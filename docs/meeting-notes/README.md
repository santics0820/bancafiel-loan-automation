# Meeting Notes
**Owner:** Project Manager (or designated note-taker)

---

## 📋 Purpose

This folder contains notes from all team meetings, KPMG sessions, and important discussions.

---

## 📂 File Naming Convention

Use format: `YYYY-MM-DD-meeting-type.md`

Examples:
- `2026-02-15-team-kickoff.md`
- `2026-02-18-kpmg-session-2.md`
- `2026-02-22-sprint-demo.md`
- `2026-03-01-final-presentation-prep.md`

---

## 📝 Meeting Note Template

```markdown
# [Meeting Type] - [Date]

**Date:** February 15, 2026
**Time:** 9:00 AM - 10:30 AM
**Attendees:** [List all attendees]
**Note-taker:** [Name]

---

## Agenda
1. Item 1
2. Item 2
3. Item 3

---

## Discussion Notes

### Topic 1
- Key point 1
- Key point 2

### Topic 2
- Key point 1

---

## Decisions Made
- ✅ Decision 1
- ✅ Decision 2

---

## Action Items
- [ ] [Person] - Do task X by [date]
- [ ] [Person] - Do task Y by [date]

---

## Next Steps
- Next meeting: [Date & Time]
- Deliverables due: [List & dates]

---

## Parking Lot (Questions/Issues for later)
- Item to discuss later
```

---

## 🎯 Important Meetings to Document

1. **Team Kickoff (Session 1)** - Role assignments, project overview
2. **KPMG Session 2** - Requirements gathering, client questions
3. **Weekly Sprint Demos** - Progress updates
4. **Final Presentation Prep** - Rehearsal notes

---

**Keep detailed notes! They're valuable for tracking decisions and preventing miscommunication.**
